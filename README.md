# 写作工具

Windows 桌面纯文字写作应用，基于 Electron。

开发运行：在 process 中执行 `npm install`，随后双击 `启动写作.cmd`，或运行 `npm start`。

构建：`npm run build`。生成的 Windows 应用位于 `../output/写作工具/写作工具.exe`，整个写作工具文件夹需要一起保留。

V1.0 发布构建：`npm run build -- V1.0`，对应 Git 标签 `V1.0`，应用位于 `../output/V1.0/写作.exe`。

输入停止 500 毫秒后自动保存，窗口失去焦点及关闭时也会保存。作品、书名、正文、章节和字号存放在 Electron 用户数据目录的 `library.json` 中，采用临时文件写入后替换。保存失败会显示提示并重试，关闭前保存失败时会保留窗口。

中文使用宋体，英文使用 Times New Roman。字号范围为 16–36，正文连续上下滚动，支持中文输入法，仅保存纯文字。

左上角按钮展开或收起章节目录。鼠标靠近段落开头左侧时出现类型按钮，可将段落设为“章标题”（一级）、“节标题”（二级）或“正文”。目录实时更新，点击标题跳到对应段落。也可用 Ctrl+Shift+P 打开当前段落的类型菜单。Enter 新建段落默认使用正文。

旧版纯文字稿会按换行读取为正文段落。新版自动保存纯文字及段落类型，原稿不需要手动转换。

首页管理作品，可新建作品和修改书名。进入作品后，顶部显示书名；不同作品独立保存。首次运行新版时，旧的 manuscript.json 自动迁移为未命名作品，原文件保留。
